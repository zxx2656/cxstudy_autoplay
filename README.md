# 学习通自动连播 (cxstudy_autoplay)

一个 Windows 桌面小工具：接管一个**专用的调试版浏览器**，自动检测超星学习通网页端的视频并连续播放
——播完自动进入下一个任务、遇到章节测验自动跳过、已完成的视频不重播、被暂停/卡住自动恢复。

> 只有托盘图标一个界面，不弹窗、不抢焦点、不碰你日常使用的浏览器。
> 目标浏览器为 **Microsoft Edge**（Windows 10/11 自带，免安装）。

---

## 功能

| 功能 | 说明 |
|---|---|
| 自动连播 | 检测到学习通视频页后自动接管，播完自动进入下一个任务 |
| 跳过章节测验 | 遇到没有视频的任务（章节测验/作业）自动前进跳过 |
| 已完成不重播 | 页面标记「任务点已完成」的任务直接跳过 |
| 自动恢复 | 视频被暂停/卡住时自动 `play()` 或点击播放按钮 |
| 自动确认弹窗 | 自动接受 confirm/alert（跳过测验常被「确定离开？」拦住） |
| 到末尾干净停下 | 目录里没有后续任务时停止前进并提示，不会乱点 |
| 与你日常浏览器隔离 | 使用程序自己的浏览器配置，是独立实例，互不影响 |
| 退出即清理 | 退出时只关闭"本程序启动的那个浏览器实例"，绝不动你自己的浏览器 |

## 工作原理

```
① 启动专用浏览器
   --user-data-dir=程序自己的配置目录   (与你的浏览器隔离;
                                       且必须非"默认目录", 否则浏览器会禁用调试端口)
   --remote-debugging-port=<空闲端口>   (开启本机 CDP 控制通道)
   + 启动页 = 学习通登录页
        ↓
② 只读发现:  HTTP GET http://127.0.0.1:<端口>/json/list
   仅读取页面清单, 不建立任何连接 —— 未开启连播时对浏览器零接触
        ↓
③ 按需接管:  只对"学习通域名"的页面建立 WebSocket(CDP)
   其它标签(B 站等)永不接触
        ↓
④ 帧枚举:    Page.getFrameTree 找出播放器所在的子 iframe
        ↓
⑤ 每秒读取:  video.paused / currentTime / duration / ended
        ↓
⑥ 状态机决策: 继续播放 / 恢复播放 / 跳过 / 前进 / 停下
```

**前进方式**：优先"目录跳转"——从当前地址取 `chapterId`，在课程侧栏目录里精确定位当前任务，
再点它的下一项。这样是确定性跳转、能跨章节，且**不会跑到课程首页**。

> 为什么必须带调试参数？这是 Chromium 的安全机制：只有启动时开启调试端口的浏览器才能被程序控制；
> 且 136+ 版本对「默认配置目录」直接禁用该端口，所以本程序使用独立的配置目录。

## 环境要求

- Windows 10 / 11
- **Microsoft Edge** —— 系统自带，通常无需额外安装
  （也可在 `config.py` 里改为 Chrome / 夸克等其它 Chromium 内核浏览器）
- 从源码运行需要 Python 3.9+ ；使用 `dist\CxAuto\CxAuto.exe` 则无需 Python

## 使用方法

### 方式一：直接使用打包好的程序

1. 运行 `dist\CxAuto\CxAuto.exe`
2. 程序会自动打开一个专用浏览器并停在**学习通登录页**
3. 在该浏览器里**登录 → 进入课程 → 点开一个视频**
4. 右键任务栏右下角的托盘图标 → 勾选「**自动连播**」
5. 想停就点「暂停连播」；结束时点「退出(同时关闭专用浏览器)」

> 若托盘图标被 Win11 折叠进 `^` 区：把它拖到任务栏即可固定（程序也会尝试自动设为常显）。

### 方式二：从源码运行

```bat
pip install -r requirements.txt
启动.bat
```

### 托盘菜单

```
自动连播          ← 勾选开关(核心)
────────────────
暂停连播
继续连播
────────────────
打开学习通登录页
────────────────
退出(同时关闭专用浏览器)
```

## 打包

```bat
build.bat
```

- 方式：PyInstaller **onedir**（启动快、体积可控、不在运行时解压）
- 产物：`dist\CxAuto\CxAuto.exe`（约 16–22 MB）
- 已排除用不到的模块（tkinter / numpy / sqlite3 / ssl / _hashlib 等）并裁剪 PIL 二进制以减小体积
- **注意**：不要排除 `email` —— `urllib.request` 依赖它，排除后程序无法启动

## 目录结构

```
cxstudy_autoplay/
├── main.py              # 程序入口(仅托盘界面)
├── config.py            # 配置: 浏览器 / 日志 / 行为开关 / 选择器 / 阈值
├── browser_manager.py   # 专用浏览器管理(轻量 CDP 接管)
├── video_controller.py  # 播放状态机(前进/跳过/恢复)
├── cdp.py               # 极简 Chrome DevTools Protocol 客户端(无第三方依赖)
├── 启动.bat             # 源码方式启动
├── build.bat            # 一键打包
├── cxauto.ico           # 程序图标
├── requirements.txt
├── tests/               # 回归测试(覆盖已修复的真实故障)
└── dist/                # 打包产物(不纳入版本管理)
```

运行时产生的文件（不纳入版本管理）：
- 浏览器专用配置：`%LOCALAPPDATA%\cxauto\quark-profile\`
- 浏览器路径记忆（手动指定时）：`%LOCALAPPDATA%\cxauto\browser_path.txt`
- 崩溃日志（**仅异常时生成**）：`%LOCALAPPDATA%\cxauto\crash.log`
- 运行日志：**源码运行时**写在程序目录；**打包后不再写日志**

## 配置（config.py）

| 配置项 | 说明 |
|---|---|
| `BROWSER_NAME` / `BROWSER_EXE_CANDIDATES` | 目标浏览器（默认 Microsoft Edge；改这里即可换 Chrome / 夸克） |
| `BROWSER_PROFILE` | 专用浏览器配置目录（必须非默认目录） |
| `LOGIN_URL` | 启动后自动打开的登录页 |
| `AUTO_START` | 是否启动即自动连播（默认 `False`，由托盘手动开启） |
| `CLOSE_BROWSER_ON_EXIT` | 退出时是否关闭专用浏览器（默认 `True`） |
| `CLEAR_PROFILE_ON_EXIT` | 退出时是否清空浏览器配置（默认 `False`） |
| `LOG_IN_PACKAGED` / `CRASH_LOG` | 打包后是否写运行日志 / 是否写崩溃日志 |
| `MAX_ADVANCE_STREAK` 等 | 前进上限、等待宽限等阈值 |

浏览器定位顺序：**手动指定 → 常见安装路径 → 注册表 → 各盘浅层搜索**；
都找不到时会提示把路径写入 `%LOCALAPPDATA%\cxauto\browser_path.txt`。

## 常见问题

**Q: 托盘上没有图标？**
A: Win11 默认把新的托盘图标折叠进 `^` 区，点 `^` 展开并把它拖到任务栏即可固定。

**Q: 提示"使用了特殊参数打开，具有较低的稳定性和安全性"？**
A: 这是浏览器的安全提示。程序必须让浏览器开启调试端口才能控制它，属于必要代价。

**Q: 换个电脑会不会找不到浏览器？**
A: 程序会按"手动指定 → 常见路径 → 注册表 → 各盘搜索"依次查找；仍找不到时会提示手动指定路径（只需一次）。

**Q: 为什么已完成的视频不重播？**
A: 页面标记「任务点已完成」即跳过——重复观看没有意义。

**Q: 怎么做才能继续到下一章？**
A: 目录里若包含后续章节，程序会自然继续；若提示"已到本章/课程末尾"，手动进入下一章的任务页即可继续自动连播。
